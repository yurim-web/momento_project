# Momento — 디자인 시스템 가이드

## 1. 디자인 컨셉

### 키워드
**감성적 · 파스텔 톤 · 손글씨 느낌 · 따뜻한 · 부드러운**

### 무드
커플의 따뜻한 일상을 담는 공간답게, 부드러운 파스텔 색상과 손글씨 폰트를 조합하여 아날로그 감성을 디지털로 표현한다.

---

## 2. 색상 팔레트 (Color Palette)

### Primary — Pink (핑크)
주요 강조색. 버튼, 활성 상태, 포인트 요소에 사용.

| Token | Hex | 용도 |
|-------|-----|------|
| `pink-50` | `#fef7f7` | 입력 필드 배경 |
| `pink-100` | `#fdeef0` | 카드 테두리, 섹션 배경 |
| `pink-200` | `#fbd5dc` | 입력 필드 테두리, 태그 배경 |
| `pink-300` | `#f8b4c0` | 그라데이션 시작, 아이콘 |
| `pink-400` | `#f48da0` | 활성 텍스트, 포커스 |
| `pink-500` | `#e8687e` | 강조 텍스트, 활성 네비게이션 |

## 3. 타이포그래피 (Typography)

### 폰트 패밀리

| 용도 | 폰트 | CSS Class | 설명 |
|------|------|-----------|------|
| 본문 | Gowun Batang | `font-hand` | 한국어 세리프, 따뜻한 느낌 |
| 제목/손글씨 | Nanum Pen Script | `font-display` / `.font-handwriting` | 손글씨 느낌의 제목 |

### 텍스트 크기 가이드

| 용도 | 크기 | 예시 |
|------|------|------|
| 페이지 제목 | `text-3xl` ~ `text-4xl` | D+Day 숫자, 페이지 타이틀 |
| 섹션 제목 | `text-xl` ~ `text-2xl` | "최근 이야기", "오늘의 한마디" |
| 카드 제목 | `text-sm` ~ `text-base` | 게시글 제목, 일기 제목 |
| 보조 텍스트 | `text-xs` ~ `text-sm` | 날짜, 작성자, 카테고리 |

## 4. 컴포넌트 (Components)

### 4.1 카드 — `.card-pastel`
```css
background: white;
border-radius: 1.5rem;
box-shadow: 0 2px 16px rgba(232, 104, 126, 0.08);
border: 1px solid #fdeef0;
```
- 모든 콘텐츠 영역에 사용
- 호버 시 `scale-[1.01]` 트랜지션

### 4.2 입력 필드 — `.input-pastel`
```css
padding: 0.75rem 1rem;
border: 1.5px solid #fbd5dc;
border-radius: 1rem;
background: #fef7f7;
font-family: 'Gowun Batang', serif;
```
- 포커스: 테두리 `#f48da0`, 그림자 `rgba(244, 141, 160, 0.15)`
- placeholder 색상: `#d4a0aa`

### 4.3 Primary 버튼 — `.btn-primary`
```css
background: linear-gradient(135deg, #f8b4c0, #8ec2ff);
color: white;
border-radius: 1rem;
font-weight: 700;
```
- 호버: `translateY(-1px)`, 핑크 그림자
- 전체 너비 (`width: 100%`)

### 4.4 Secondary 버튼 — `.btn-secondary`
```css
background: white;
color: #e8687e;
border: 1.5px solid #fbd5dc;
border-radius: 1rem;
```
- 호버: 배경 `#fef7f7`, 테두리 `#f48da0`

### 4.5 카테고리 태그
```html
<span class="text-xs px-2 py-0.5 rounded-full bg-pink-100 text-pink-400">
  데이트
</span>
```

### 4.6 이모지 선택 버튼
```html
<!-- 비선택 -->
<button class="p-3 rounded-2xl border-2 border-pink-100">😊</button>
<!-- 선택됨 -->
<button class="p-3 rounded-2xl border-2 border-pink-400 bg-pink-50">😊</button>
```

## 5. 레이아웃 (Layout)

### 페이지 구조
```
<div class="min-h-screen bg-cream-50">
  <Navbar />                              <!-- 상단 고정 -->
  <main class="max-w-4xl mx-auto px-4 py-8 pb-24 md:pb-8">
    <!-- 콘텐츠 -->
  </main>
  <!-- 모바일 하단 네비 (Navbar 내부) -->
</div>
```

### 반응형 분기점
| 분기점 | 너비 | 네비게이션 |
|--------|------|------------|
| 모바일 | ~767px | 하단 고정 탭 바 |
| 데스크톱 | 768px~ | 상단 헤더 메뉴 |

### 최대 너비
- 콘텐츠 영역: `max-w-4xl` (896px)
- 인증 페이지: `max-w-md` (448px)

## 7. 인터랙션 & 애니메이션

| 요소 | 효과 |
|------|------|
| 카드 호버 | `scale-105` or `scale-[1.01]`, `transition-transform` |
| 버튼 호버 | `translateY(-1px)`, 그림자 증가 |
| 입력 포커스 | 테두리 색상 변경 + 외곽 그림자 |
| 네비 전환 | `transition-colors` |
| 전체 | `transition: all 0.2s ease` |
