| 항목 | 버전 |

| Port | 3306 |
| Database | Momento |

### 실행 명령어
```bash

mysql.server start
```

```sql
CREATE DATABASE IF NOT EXISTS Momento;
USE Momento;
SHOW TABLES;
```

### MySQL 중지
```bash
brew services stop mysql
# 또는
mysql.server stop
```

## 2. 백엔드 서버 (Spring Boot)

- **포트**: 8081
- **경로**: `momento/backup/`

### 실행 명령어
```bash
# 백엔드 디렉토리로 이동
cd ~/Desktop/momento/backup

# 서버 실행
./mvnw spring-boot:run
```

### 정상 실행 확인
```bash
# 다른 터미널에서 확인
curl http://localhost:8081/api/posts
# 정상이면 JSON 배열 응답 (예: [{"id":1, ...}])
```

### 포트 충돌 시 (Port 8081 already in use)
```bash
# 8081 포트 사용 중인 프로세스 확인
lsof -ti:8081

# 해당 프로세스 종료
kill $(lsof -ti:8081)

# 다시 실행
./mvnw spring-boot:run
```

### 백엔드 중지
```
해당 터미널에서 Ctrl + C
```

## 3. 프론트엔드 서버 (Next.js)

- **포트**: 3000 (사용 중이면 3001로 자동 변경)
- **경로**: `momento/`

### 실행 명령어
```bash
# 프로젝트 루트로 이동
cd ~/Desktop/momento

# 개발 서버 실행
npm run dev

# 프로덕션 빌드 후 실행
npm run build
npm start
```

### 정상 실행 확인
> 브라우저에서 http://localhost:3000 접속
> (포트가 3001이면 http://localhost:3001)

### 캐시 초기화 후 재시작
```bash
rm -rf .next
npm run dev
```

### 프론트엔드 중지
```
해당 터미널에서 Ctrl + C
```

## 한 번에 전부 실행하기

터미널 3개를 열고 순서대로 실행:

```bash
# 터미널 1 - MySQL
brew services start mysql

# 터미널 2 - 백엔드
cd ~/Desktop/momento/backup && ./mvnw spring-boot:run

# 터미널 3 - 프론트엔드
cd ~/Desktop/momento && npm run dev
```

> MySQL → 백엔드 → 프론트엔드 순서로 실행해야 합니다!

## 자주 발생하는 문제

### "서버에 연결할 수 없습니다"
→ 백엔드 서버가 안 켜져 있음
```bash
cd ~/Desktop/momento/backup && ./mvnw spring-boot:run
```

### "Port 8081 was already in use"
→ 이미 백엔드가 실행 중
```bash
kill $(lsof -ti:8081)
./mvnw spring-boot:run
```

### 페이지가 안 뜨거나 JS 404 에러
→ Next.js 캐시 문제
```bash
rm -rf .next
npm run dev
```

### CORS 에러 (Access-Control-Allow-Origin)
→ 프론트엔드 포트와 백엔드 CORS 설정 불일치
→ `backup/src/.../config/CorsConfig.java`에서 허용 포트 확인
→ 현재 허용: localhost:3000, 3001, 3002

### MySQL 연결 실패
→ MySQL 서비스 미실행
```bash
brew services start mysql
```
