# Momento — 기능 명세서

## 1. 인증 (Authentication)

### 1.1 회원가입
- **경로**: `/signup`
- **설명**: 새로운 사용자 등록
- **입력 필드**:

| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 이름 | text | O | 빈 값 불가 |
| 이메일 | email | O | 이메일 형식 |
| 비밀번호 | password | O | 빈 값 불가 |
| 비밀번호 확인 | password | O | 비밀번호와 일치 |
| 전화번호 | tel | O | 빈 값 불가 |

- **동작 흐름**:
  1. 폼 입력 → 비밀번호 일치 검증
  2. `POST /user/signup` 호출
  3. 성공 → 로그인 페이지로 이동
  4. 실패 → 에러 메시지 표시

### 1.2 로그인
- **경로**: `/login`
- **설명**: 기존 사용자 인증
- **입력 필드**:

| 필드 | 타입 | 필수 |
|------|------|------|
| 이메일 | email | O |
| 비밀번호 | password | O |

- **동작 흐름**:
  1. 폼 입력 → `POST /user/login` 호출
  2. 응답 `status === 'success'` → localStorage에 userEmail, userName 저장 → 홈 이동
  3. 실패 → "이메일 또는 비밀번호가 올바르지 않습니다" 표시

- **세션 관리**: localStorage 기반 (userEmail, userName)

## 2. 홈 대시보드

- **경로**: `/`
- **컴포넌트**: Navbar + 4개 섹션

### 2.1 D+Day 카운터
- 커플 프로필 아바타 (나 ♥ 당신)
- 사귄 날짜부터 오늘까지 일수 계산
- 시작일 표시

### 2.2 오늘의 한마디
- 그라데이션 배경 카드
- 커플이 설정한 메시지 표시

### 2.3 퀵 메뉴
- 4x1 그리드: 글쓰기, 일기, 캘린더, 기념일
- 각 항목 클릭 시 해당 페이지로 이동

### 2.4 최근 이야기
- 최근 게시글 3개 미리보기
- 카테고리 태그, 제목, 날짜, 작성자 표시
- "전체보기" 링크 → `/posts`

## 3. 게시글 (Posts)

### 3.1 게시글 목록
- **경로**: `/posts`
- **기능**:
  - 카테고리 탭 필터: 전체 / 데이트 / 여행 / 일상 / 기념일 / 맛집
  - 게시글 카드: 카테고리 태그, 제목, 미리보기 텍스트, 날짜, 장소, 작성자
  - 빈 상태: "아직 작성된 글이 없어요" + 글쓰기 버튼
  - 플로팅 글쓰기 버튼 (우하단)

### 3.2 게시글 작성
- **경로**: `/posts/new`
- **입력 필드**:

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 카테고리 | select | O | 데이트/여행/일상/기념일/맛집 |
| 제목 | text | O | |
| 날짜 | date | X | 이벤트 날짜 |
| 장소 | text | X | |
| 내용 | textarea | O | |
| 사진 | file | X | 미구현 (UI만 존재) |

- **동작**: 저장 시 `POST /api/posts` → 성공 시 목록으로 이동

### 3.3 게시글 상세
- **경로**: `/posts/[id]`
- **표시 정보**: 카테고리, 제목, 작성자, 날짜, 장소, 내용
- **기능**:
  - 삭제 버튼 (confirm 확인 후 `DELETE /api/posts/{id}`)
  - 댓글 섹션 (하단)

### 3.4 댓글
- **위치**: 게시글 상세 페이지 하단
- **기능**:
  - 댓글 목록 조회 (`GET /api/posts/{postId}/comments`)
  - 댓글 작성 (`POST /api/posts/{postId}/comments`)
  - 댓글 삭제 (`DELETE /api/posts/comments/{commentId}`)
  - 본인 댓글만 삭제 가능 (이메일 비교)

## 4. 일기장 (Diary)

### 4.1 일기 목록
- **경로**: `/diary`
- **기능**:
  - 필터 탭: 전체 / 내 일기
  - 일기 카드: 기분 이모지, 제목, 미리보기, 날짜, 작성자, 공유 여부 뱃지
  - 빈 상태 + 일기 쓰기 버튼
  - 플로팅 글쓰기 버튼

### 4.2 일기 작성
- **경로**: `/diary/write`
- **입력 필드**:

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 기분 | emoji select | O | 😊😍😌🥰🌧😢😴😤 중 선택 |
| 제목 | text | O | |
| 날짜 | date | O | 기본값: 오늘 |
| 내용 | textarea | O | |
| 공유 | toggle | O | 기본값: 공유 (커플에게 공개) |

- **기분 이모지 옵션**:

| 이모지 | 라벨 |
|--------|------|
| 😊 | 행복 |
| 😍 | 설렘 |
| 😌 | 평온 |
| 🥰 | 감사 |
| 🌧 | 그리움 |
| 😢 | 슬픔 |
| 😴 | 피곤 |
| 😤 | 화남 |

### 4.3 일기 상세
- **경로**: `/diary/[id]`
- **표시**: 기분 이모지 + 라벨, 제목, 날짜, 작성자, 공유 뱃지, 내용
- **기능**: 삭제 (confirm 후 `DELETE /api/diaries/{id}`)

## 5. 캘린더 (Calendar)

- **경로**: `/calendar`

### 5.1 월별 뷰
- 월 네비게이션 (이전/다음)
- 요일 헤더 (일~토)
- 날짜 그리드 (6주 고정)
- 이벤트가 있는 날짜에 색상 점(dot) 표시
- 오늘 날짜 하이라이트
- 선택된 날짜 핑크 배경

### 5.2 일정 목록
- 선택된 날짜의 일정 표시
- 카테고리별 색상 구분:

| 카테고리 | 색상 |
|----------|------|
| 데이트 | 핑크 |
| 기념일 | 라벤더 (하늘색) |
| 약속 | 민트 |
| 기타 | 피치 |

### 5.3 일정 추가
- "+" 버튼 클릭 → 모달 표시
- 입력: 제목, 카테고리 (select), 날짜 (선택된 날짜 기본값)
- `POST /api/calendar` 후 목록 갱신

## 6. 기념일 (Anniversary)

- **경로**: `/anniversary`

### 6.1 자동 기념일
- 사귄 날짜 기준 자동 생성:

| 기념일 | 이모지 |
|--------|--------|
| 100일 | 💕 |
| 200일 | 💖 |
| 300일 | 💗 |
| 1주년 (365일) | 🎉 |
| 500일 | 🌟 |
| 2주년 (730일) | ✨ |
| 1000일 | 👑 |

- D-Day 표시 (D-N / 오늘! / 지남)
- 지난 기념일/다가올 기념일 구분

### 6.2 커스텀 기념일

- 입력: 제목, 날짜, 이모지 선택 (💝🎂🎄🌸✈️🎵🍰📸 중)
- `POST /api/anniversaries` 후 목록 갱신
