# Momento — PRD (Product Requirements Document)

## 1. 제품 개요

### 1.1 제품명
**Momento** (모멘토)

### 1.2 한 줄 소개
커플이 함께 추억을 기록하고 공유하는 감성 블로그 웹 애플리케이션

### 1.3 제품 비전
연인 간의 소중한 일상, 데이트, 여행 등의 추억을 한 공간에 기록하고, 시간이 지나도 다시 꺼내볼 수 있는 **디지털 추억 저장소**를 만든다.

### 1.4 타겟 유저
- **주 타겟**: 20~30대 커플
- **페르소나**: 데이트 기록을 남기고 싶은 연인, 기념일을 잘 챙기고 싶은 커플, 공유 일기를 쓰고 싶은 커플

---

## 2. 문제 정의

| 문제 | 설명 |
|------|------|
| 추억 파편화 | 사진은 갤러리, 대화는 메신저, 일정은 캘린더에 흩어져 있음 |
| 기념일 놓침 | 100일, 200일 등 기념일을 깜빡하기 쉬움 |
| 기록 부재 | 데이트 감상, 감정 등 텍스트 기록이 남지 않음 |
| 공유 어려움 | 둘만의 공간에서 추억을 함께 돌아볼 수 없음 |

## 3. 핵심 기능 (Features)

### 3.1 MVP (Minimum Viable Product)

#### F1. 회원가입 / 로그인
- 이메일 + 비밀번호 기반 인증
- 로그인 후 세션 유지 (localStorage)
- 우선순위: **P0 (필수)**

#### F2. 게시글 (Posts)
- 데이트, 여행, 일상, 기념일, 맛집 카테고리 분류
- 제목, 내용, 날짜, 장소, 사진 첨부
- 댓글 기능으로 서로 소통
- CRUD (생성/조회/수정/삭제)
- 우선순위: **P0 (필수)**

#### F3. 일기장 (Diary)
- 개인 일기 & 공유 일기 구분
- 기분 이모지 선택 (8종: 행복/설렘/평온/감사/그리움/슬픔/피곤/화남)
- 날짜별 기록
- 우선순위: **P0 (필수)**

#### F4. 캘린더 (Calendar)
- 월별 일정 조회
- 카테고리별 일정 추가 (데이트/기념일/약속/기타)
- 날짜에 이벤트 점(dot) 표시
- 우선순위: **P1 (중요)**

#### F5. 기념일 (Anniversary)
- 사귄 날짜 기준 자동 기념일 생성 (100일, 200일, 300일, 365일, 500일, 730일, 1000일)
- 커스텀 기념일 추가
- D-Day 카운터
- 우선순위: **P1 (중요)**

#### F6. 홈 대시보드
- D+Day 카운터 표시
- 오늘의 한마디
- 퀵 메뉴 (글쓰기, 일기, 캘린더, 기념일)
- 최근 게시글 미리보기
- 우선순위: **P1 (중요)**

### 3.2 확장 기능 (Future)

#### F7. 갤러리 (Gallery)
- 사진 업로드 및 그리드 보기
- 사진 모달 (확대 보기)
- 월별/이벤트별 정리
- 우선순위: **P2 (보류)**

#### F8. 커플 연결 (Connect)
- 초대코드 생성
- 코드 입력으로 커플 매칭
- 매칭 후 데이터 공유
- 우선순위: **P2 (보류)**

#### F9. 프로필 (Profile)
- 커플 정보 수정
- 사귄 날짜 설정/변경
- 알림 설정
- 우선순위: **P2 (보류)**

#### F10. 사진 업로드
- 게시글/갤러리 이미지 첨부
- 이미지 리사이즈 및 저장
- 우선순위: **P2 (보류)**

## 4. 유저 스토리

### 인증
| ID | 역할 | 스토리 | 인수 조건 |
|----|------|--------|-----------|
| US-01 | 사용자 | 이메일과 비밀번호로 회원가입할 수 있다 | 이름, 이메일, 비밀번호, 전화번호 입력 후 가입 완료 |
| US-02 | 사용자 | 이메일과 비밀번호로 로그인할 수 있다 | 로그인 성공 시 홈으로 이동, 실패 시 에러 메시지 |

### 게시글
| ID | 역할 | 스토리 | 인수 조건 |
|----|------|--------|-----------|
| US-03 | 커플 | 데이트 기록을 카테고리별로 작성할 수 있다 | 제목, 내용, 카테고리, 날짜, 장소 입력 후 저장 |
| US-04 | 커플 | 게시글 목록을 카테고리별로 필터링할 수 있다 | 전체/데이트/여행/일상/기념일/맛집 탭 전환 |

| US-06 | 커플 | 게시글을 삭제할 수 있다 | 삭제 확인 후 목록에서 제거 |

### 일기장
| ID | 역할 | 스토리 | 인수 조건 |
|----|------|--------|-----------|
| US-07 | 커플 | 오늘의 기분을 이모지로 선택하고 일기를 쓸 수 있다 | 8종 이모지 중 선택, 제목/내용 작성 |

| US-09 | 커플 | 내 일기만 필터링해서 볼 수 있다 | 전체/내 일기 탭 전환 |

### 캘린더

|----|------|--------|-----------|
| US-10 | 커플 | 월별 캘린더에서 일정을 확인할 수 있다 | 이벤트 있는 날짜에 점 표시, 클릭 시 상세 |
| US-11 | 커플 | 새로운 일정을 등록할 수 있다 | 제목, 카테고리, 날짜 입력 후 저장 |

### 기념일
| ID | 역할 | 스토리 | 인수 조건 |
|----|------|--------|-----------|
| US-12 | 커플 | 사귄 날짜 기준으로 자동 기념일을 볼 수 있다 | 100일, 200일 등 자동 생성 |
| US-13 | 커플 | 커스텀 기념일을 추가할 수 있다 | 제목, 날짜, 이모지 선택 후 저장 |

## 5. 비기능 요구사항

| 항목 | 요구사항 |
|------|----------|
| 반응형 | 모바일(360px~) / 태블릿(768px~) / 데스크톱(1024px~) 대응 |
| 성능 | 페이지 로딩 3초 이내 |
| 브라우저 | Chrome, Safari, Edge 최신 2개 버전 |
| 보안 | 비밀번호 해싱, SQL Injection 방지 (JPA 사용) |
| 접근성 | 한국어 lang 설정, 시맨틱 HTML |

## 6. 기술 스택

| 영역 | 기술 | 선택 이유 |
|------|------|-----------|
| 프론트엔드 | Next.js 15 (App Router) | 최신 React 19 지원, 파일 기반 라우팅, SSR 가능 |
| UI 프레임워크 | React 19 | 컴포넌트 기반 UI, 거대한 생태계 |
| 스타일링 | Tailwind CSS 3.4 | 유틸리티 퍼스트, 빠른 UI 개발, 커스텀 테마 용이 |
| 언어 | TypeScript | 타입 안전성, 개발 생산성 |
| 백엔드 | Spring Boot 3.4 | 안정적인 Java 웹 프레임워크, JPA 통합 |
| ORM | Spring Data JPA | 자동 CRUD, 쿼리 메서드, 테이블 자동 생성 |
| 데이터베이스 | MySQL 8 | 관계형 DB, 풍부한 커뮤니티 |
| 빌드 | Maven (mvnw) / npm | 각 영역 표준 빌드 도구 |
