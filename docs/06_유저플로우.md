# Momento — 유저 플로우 & 사이트맵

## 1. 사이트맵

```
Momento
│
├── 🏠 홈 (/)
│   ├── D+Day 카운터
│   ├── 오늘의 한마디
│   ├── 퀵 메뉴 → 글쓰기 / 일기 / 캘린더 / 기념일
│   └── 최근 게시글 → 게시글 상세
│
├── 🔐 인증
│   ├── 로그인 (/login)
│   └── 회원가입 (/signup)
│
├── 🔗 커플 연결 (/connect)
│
├── ✏️ 게시글 (/posts)
│   ├── 게시글 목록 (/posts)
│   │   └── 카테고리 필터 (전체/데이트/여행/일상/기념일/맛집)
│   ├── 게시글 작성 (/posts/new)
│   └── 게시글 상세 (/posts/:id)
│       ├── 댓글
│       └── 삭제
│
├── 📖 일기장 (/diary)
│   ├── 일기 목록 (/diary)
│   │   └── 필터 (전체/내 일기)
│   ├── 일기 작성 (/diary/write)
│   └── 일기 상세 (/diary/:id)
│       └── 삭제
│
├── 📅 캘린더 (/calendar)
│   ├── 월별 뷰
│   ├── 날짜별 일정 목록
│   └── 일정 추가 (모달)
│
├── 💝 기념일 (/anniversary)
│   ├── 자동 기념일 (D+Day)
│   └── 커스텀 기념일 추가 (모달)
│
├── 🖼 갤러리 (/gallery)
│   └── 사진 그리드 + 모달 뷰
│
└── ♡ 프로필 (/profile)
    ├── 커플 정보
    ├── D-Day
    └── 설정
```

## 2. 유저 플로우

### 2.1 첫 사용 플로우 (온보딩)

```
[앱 접속]
    │
    ▼
[홈 페이지] ─── 로그인 안 됨 ───→ [로그인 페이지]
                                       │
                              ┌────────┴────────┐
                              │                  │
                         [로그인 성공]        [회원가입 링크]
                              │                  │
                              ▼                  ▼
                         [홈 이동]         [회원가입 페이지]
                                                 │
                                            [가입 완료]
                                                 │
                                                 ▼
                                           [로그인 페이지]
```

### 2.2 게시글 작성 플로우

```
[홈] ── 퀵메뉴 "글쓰기" ──→ [게시글 작성]
  │                              │
  │                         카테고리 선택
  │                         제목/내용 입력
  │                         날짜/장소 입력 (선택)
  │                              │
  │                         [저장 버튼]
  │                              │
  │                              ▼
  │                         [게시글 목록] ←── 게시글 카드 클릭 ──→ [게시글 상세]
  │                              │                                    │
  │                         카테고리 탭                           댓글 작성/삭제
  │                         전환                                  게시글 삭제
  │                              │                                    │
  └──────────────────────────────┘                                    │
                                                                [목록으로 이동]
```

### 2.3 일기 작성 플로우

```
[홈] ── 퀵메뉴 "일기" ──→ [일기 작성]
  │                            │
  │                       기분 이모지 선택 (8종)
  │                       제목/날짜/내용 입력
  │                       공유/비공개 토글
  │                            │
  │                       [저장 버튼]
  │                            │
  │                            ▼
  │                       [일기 목록] ←── 일기 카드 클릭 ──→ [일기 상세]
  │                            │                                │
  │                       전체/내 일기                       일기 삭제
  │                       필터 전환                              │
  └────────────────────────────┘                           [목록으로 이동]
```

### 2.4 캘린더 플로우

```
[홈] ── 퀵메뉴 "캘린더" ──→ [캘린더]
                                │
                           월 네비게이션 (◀ ▶)
                                │
                           날짜 클릭 → 해당 날짜 일정 표시
                                │
                           "+" 버튼 클릭
                                │
                                ▼
                           [일정 추가 모달]
                                │
                           제목/카테고리/날짜 입력
                                │
                           [추가 버튼]
                                │
                                ▼
                           캘린더에 이벤트 점 표시
```

### 2.5 기념일 플로우

```
[홈] ── 퀵메뉴 "기념일" ──→ [기념일]
                                │
                    ┌───────────┴───────────┐
                    │                        │
              [자동 기념일]             [커스텀 기념일]
              100일, 200일 등           "기념일 추가" 클릭
              D-Day 카운트다운                │
                                             ▼
                                       [추가 모달]
                                             │
                                       제목/날짜/이모지
                                             │
                                       [추가 버튼]
                                             │
                                             ▼
                                       목록에 추가됨
```

## 3. 페이지 전환 맵

```
                    ┌─────────┐
                    │  Login  │
                    └────┬────┘
                         │ 성공
                         ▼
┌──────┐  ◀──────  ┌─────────┐  ──────▶  ┌──────────┐
│Signup│           │   Home  │           │  Posts   │ ──▶ New ──▶ Detail
└──────┘           └────┬────┘           └──────────┘
                        │
          ┌─────────────┼─────────────┐
          │             │             │
          ▼             ▼             ▼
    ┌──────────┐  ┌──────────┐  ┌──────────┐
    │  Diary   │  │ Calendar │  │Anniversary│
    └────┬─────┘  └──────────┘  └──────────┘
         │
         ├──▶ Write
         └──▶ Detail

    ┌──────────┐  ┌──────────┐  ┌──────────┐
    │ Gallery  │  │ Profile  │  │ Connect  │
    └──────────┘  └──────────┘  └──────────┘
```

**네비게이션 바에서 직접 접근 가능한 페이지**: 홈, 게시글, 일기장, 캘린더, 갤러리, 프로필

## 4. 인증 상태별 접근

| 페이지 | 비로그인 | 로그인 |
|--------|----------|--------|
| 홈 | O (읽기) | O |
| 로그인 | O | 리다이렉트 불필요 (현재 미구현) |
| 회원가입 | O | O |
| 게시글 목록 | O (읽기) | O |
| 게시글 작성 | X (로그인 필요) | O |
| 일기 목록 | O (읽기) | O |
| 일기 작성 | X (로그인 필요) | O |
| 캘린더 | O (읽기) | O |
| 기념일 | O (읽기) | O |
| 갤러리 | O | O |
| 프로필 | O (읽기) | O |
| 커플 연결 | X | O |

> 현재 인증 가드(route guard)는 미구현. 작성 페이지에서 localStorage 체크 후 알림 처리.
