# Momento — 아키텍처 & 폴더 구조

## 1. 시스템 아키텍처

```
┌─────────────────────┐     HTTP (REST)     ┌─────────────────────┐     JDBC     ┌──────────┐
│                     │ ──────────────────→  │                     │ ──────────→  │          │
│   Next.js 15        │     localhost:8081   │   Spring Boot 3.4   │              │  MySQL 8 │
│   (React 19 + TS)   │ ←──────────────────  │   (JPA + Hibernate) │ ←──────────  │ Momento  │
│                     │     JSON Response    │                     │    Result    │          │
│   localhost:3000    │                      │   localhost:8081    │              │          │
└─────────────────────┘                      └─────────────────────┘              └──────────┘
       │                                              │
       │ Tailwind CSS                                 │ CORS 허용
       │ Google Fonts                                 │ (localhost:3000)
       │ localStorage (인증)                           │ ddl-auto=update
```

### 통신 흐름
1. 사용자가 브라우저에서 Next.js 페이지 접속
2. React 컴포넌트에서 `fetch()` 로 Spring Boot API 호출
3. Spring Boot가 JPA를 통해 MySQL 쿼리 실행
4. JSON 응답을 React 컴포넌트에서 렌더링

## 2. 프론트엔드 아키텍처

### 라우팅 (App Router)
Next.js 15 App Router 기반. 각 폴더가 하나의 라우트를 형성.

```
src/app/
├── layout.tsx          # 루트 레이아웃 (HTML head, body)
├── page.tsx            # / (홈)
├── not-found.tsx       # 404
├── globals.css         # 전역 스타일
├── login/page.tsx      # /login
├── signup/page.tsx     # /signup
├── connect/page.tsx    # /connect
├── posts/
│   ├── page.tsx        # /posts (목록)
│   ├── new/page.tsx    # /posts/new (작성)
│   └── [id]/page.tsx   # /posts/:id (상세)
├── diary/
│   ├── page.tsx        # /diary (목록)
│   ├── write/page.tsx  # /diary/write (작성)
│   └── [id]/page.tsx   # /diary/:id (상세)
├── calendar/page.tsx   # /calendar
├── anniversary/page.tsx # /anniversary
├── gallery/page.tsx    # /gallery
└── profile/page.tsx    # /profile
```

### 컴포넌트 구조
```
src/components/
└── Navbar.tsx          # 전역 네비게이션 (상단 헤더 + 모바일 탭 바)
```

### 데이터 레이어
```
src/lib/
└── api.ts              # API 클라이언트
                        # - fetchApi(): 공통 fetch 래퍼
                        # - userApi: 로그인/회원가입
                        # - postApi: 게시글 CRUD + 댓글
                        # - diaryApi: 일기 CRUD
                        # - calendarApi: 캘린더 CRUD
                        # - anniversaryApi: 기념일 CRUD
```

### 타입 정의
```
src/types/
└── user.ts             # User, LoginRequest/Response, SignupRequest/Response 등
```

### 상태 관리
- **인증**: `localStorage` (userEmail, userName)
- **페이지 상태**: React `useState` (각 컴포넌트 로컬)
- **전역 상태 관리 라이브러리**: 미사용 (규모 상 불필요)

## 3. 백엔드 아키텍처

### 레이어 구조 (3-Tier)

```
Controller (REST API)
    ↓ 요청 처리, 응답 반환
Service (비즈니스 로직)
    ↓ CRUD 로직
Repository (데이터 접근)
    ↓ JPA 쿼리
Entity (DB 매핑)
    ↓ @Entity
MySQL Database
```

### 패키지 구조
```

│   ├── CalendarEventService.java
```

## 5. 주요 기술 의사결정

| 결정 | 선택 | 이유 |
|------|------|------|
| 프론트엔드 프레임워크 | Next.js 15 (App Router) | 파일 기반 라우팅, React 19 지원, SSR 가능 |
| 스타일링 | Tailwind CSS | 유틸리티 퍼스트로 빠른 개발, 커스텀 파스텔 테마 적용 용이 |
| 폰트 | Google Fonts (CDN) | 별도 설치 없이 한국어 감성 폰트 적용 |
| 상태 관리 | localStorage + useState | 소규모 프로젝트로 Redux 등 불필요 |
| 백엔드 프레임워크 | Spring Boot 3.4 | 안정적, JPA 통합, 빠른 REST API 구축 |
| ORM | Spring Data JPA | 자동 CRUD, ddl-auto로 테이블 자동 생성 |
| DB | MySQL 8 | 관계형 데이터 모델에 적합, 널리 사용 |
| 인증 | localStorage | MVP 단계 간편 구현 (추후 JWT 전환) |
| CORS | WebMvcConfigurer | Spring Boot 내장 CORS 설정 |
